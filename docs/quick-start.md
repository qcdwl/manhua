## 1. 安装并登录

从 [主下载入口](https://mh.xylos.cn/downloads/AI-Comic-Workbench-Setup.exe) 下载 Windows `.exe` 安装包；如无法下载，可使用 [GitHub 备用下载](https://github.com/qcdwl/manhua/releases/latest/download/AI-Comic-Workbench-Setup.exe)。安装后双击桌面上的“AI漫画工作台”，在登录页面注册或登录账号。

## 2. 配置接口

根据完整教程，配置推理、分镜润色和生图所需的 API。模型名称和可用选项会随在线服务调整，以工具当前显示为准。

不要将自己的 API 密钥、账号密码或完整配置截图发到公开 Issue。

## 3. 准备内容

准备已获准使用的小说内容，整理故事、角色及分镜。教程介绍了大眼火柴人、单页手绘、Q版古风、现代韩漫等画风方向，可按内容选择合适的表现方式。

## 4. 角色与分镜

先进行角色推理并制作角色图，再导入分镜内容。检查人物名称、情节顺序、场景描述以及每页文字，避免带着内容错误继续生图。

## 5. 润色与测试

使用 AI 润色，并按需要统一提示词前后缀。建议先测试前 10 页，检查画风、角色外观、构图和文字效果，满意后再继续制作。

## 6. 检查与导出

逐页检查图片，特别关注封面和开篇画面。完成需要的遮盖处理后导出素材。

## 7. 后续剪辑与发布

导出的图片可以继续用剪映制作视频。选配音、字幕、音乐及节奏后，再按发布平台要求上传作品；如所参与的推广流程要求回填，请按相应教程完成回填。

剪映剪辑、平台发布和推广回填不是客户端自动完成的功能。
